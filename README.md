# 落地 Android App · 1.0.5

按原有界面与新增七张生活习惯参考图实现的离线安卓应用，使用用户提供的“落地”图标。

## 安装

将 `Luodi-1.0.5.apk` 下载到安卓手机并安装。最低系统为 Android 6.0（API 23）；包名 `cn.luodi.app`，目标 API 34。无需账号、网络或额外存储权限。

- 将七张参考图整理为 7 个主题、62 条可操作的内容：睡前准备、善待自己、人际提醒、保护边界、安心休息、轻量自律、身体小习惯。人际内容围绕具体行为和边界，身体内容保留可选性。

## 功能

- 暂停首页：点一下开始 10 秒暂停。时间结束后可选择回到当下或继续整理。
- 事情分流：输入事情，选择责任范围、事实或猜测、重要程度，生成对应建议并保存。建议根据选择生成，不推断他人意图。
- 事情清单：使用 SortableJS 进行触屏拖动排序；支持移动到不同重要程度、标记完成和回看记录。
- 控制圈、专注圈：呈现可控制与不可控制的范围，入口连接到整理与能量补给。
- 能量补给：记录完成的小事、觉察消耗，支持散步 10 分钟和放下手机 5 分钟计时。
- 我的：统计、历史、轻触反馈开关、JSON 备份导出和确认后导入、确认后清空记录。

记录保存在应用私有 SharedPreferences。计时使用绝对结束时间，离开或重启后重新核对；没有后台通知，时间结束时若应用在后台，会在再次打开时显示完成。

## 构建

这是原生 Android Activity 与本地 HTML/CSS/JavaScript 组成的 APK，页面内嵌运行，不会跳转浏览器。没有在线网页依赖。

在 Linux 上安装 Python 3 与 Java 17（含 keytool），运行：

```sh
python3 bootstrap.py
```

脚本获取 Android 官方 SDK 35 与 Eclipse ECJ 3.37.0，验证 `toolchain-lock.json` 的 SHA-256 后构建。已配置工具链时可直接运行 `build.py`；`LUODI_TOOLCHAIN` 可指定工具链目录。当前 APK 采用 `signing/luodi-release.jks` 中的项目签名；后续覆盖更新应沿用这把签名密钥。公开仓库不包含私钥或签名密码。完整原始源码包、原签名与密码保存在私有备份分支。

## 验证

当前版本 62 项交互检查通过，并在 320、393、432 像素宽度检查布局。

`test-app.cjs` 使用 Playwright 在触屏设备模拟下检验实际页面交互、持久化、拖动、备份确认、输入转义、倒计时恢复和离线运行；`test-report.json` 记录结果。测试需要 Node.js 与 Playwright，可用 `LUODI_CHROME` 指向已有 Chromium。

`build-report.json` 包含安装包哈希和兼容性信息。Android SDK apksigner 验证 v1、v2、v3 签名；aapt 验证包名、启动 Activity、图标和 API 等级。没有 ARM/x86 原生库限制。

当前环境没有安卓真机或模拟器，尚未验证原生 Activity 生命周期、系统文件选择器、实际手机 WebView 和振动反馈。截图来自移动端浏览器测试，不代表真机安装测试。

界面按参考图实现为可操作页面；字体、图标线条与响应式布局做了适配，并非逐像素一致。安装后请先尝试一次暂停、一次事情保存和退出重开，确认本机 WebView 正常。
